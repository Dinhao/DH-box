# DH-BOX v1.1.0 发布说明

发布日期：2026-10-31 | 上一版本：[v1.0.0](RELEASE-v1.0.0.md)

## 发布包

`DH-BOX-v1.1.0-win64.zip`，解压后：

| 文件 | 说明 |
| --- | --- |
| `DH-BOX.exe` | 主程序（界面已内嵌，约 213 KB） |
| `Microsoft.Web.WebView2.Core.dll` | WebView2 运行时绑定 |
| `Microsoft.Web.WebView2.WinForms.dll` | WebView2 WinForms 宿主 |
| `WebView2Loader.dll` | WebView2 加载器 |
| `使用说明.txt` | 使用与安全说明 |

双击 `DH-BOX.exe` 即可运行；数据（`DH-BOX.vault`、`Vault.config`、`vault.log`）全部保存在程序同目录，绿色便携、不写注册表。

## 本次更新

### 新功能
- **多选与框选**：Ctrl/Shift + 单击多选、Ctrl+A 全选、Esc 取消；鼠标框选（全内容区）；状态栏显示「已选 N 项 / 合计大小」
- **与系统剪贴板互通**：资源管理器 Ctrl+C/X → 软件内 Ctrl+V 加密导入（剪切自动删除源文件）；软件内 Ctrl+C → 系统剪贴板放解密临时副本
- **Windows 系统文件图标**（按扩展名、文件夹独立图标）
- **密码支持中文/符号/emoji**；设置密码界面新增强度建议提示

### 体验修复
目录树点击、顶部边缘缩放、任务栏最小化、日志路径显示、空白处右键粘贴、框选三处问题、自动锁定时长「＋」按钮、中文输入法按 Enter 误触发、纯中文密码强度误判

### 安全加固
- **容器格式 v3**：条目目录（文件名/大小/时间/顺序）增加 HMAC-SHA256 完整性校验，解锁与找回时验证，被篡改即拒绝打开
- 加密算法与参数**完全不变**：AES-256-CBC + HMAC-SHA256（Encrypt-then-MAC）、PBKDF2-HMAC-SHA256（16B 随机盐 + 200,000 次迭代）、主密钥加密级随机、改密码零重加密

## 兼容性

- **旧库可直接打开**（v1/v2）；首次写入或改密时自动升级为 v3
- 升级后**旧版程序无法打开新库**（建议只保留 v1.1.0）
- 密码不做规范化：全角/半角、空格均视为不同字符

## 验证

- 核心逻辑自动化测试 **55 项全部通过**（`run_tests.ps1`）
- 符号密码矩阵 **7 组全部通过**（ASCII 全部符号 / 全角符号 / emoji / 引号+反斜杠+反引号 / 制表符 / 首尾空格 / 混合）
- 篡改检测实测：修改容器内条目名后解锁被拒绝
