## DH-BOX v1.0.0 · 首个公开版本

一款 Windows 本地文件加密保险库：界面由网页（WebView2）渲染，加密在 C# 后端完成。

### 📥 下载
- **DH-BOX-v1.0.0-win64.zip** —— 解压后双击 `DH-BOX.exe` 即用（界面已内嵌，无需其它文件）
- 校验和见 `SHA256SUMS.txt`

### 🔐 加密
- AES-256-CBC + HMAC-SHA256（Encrypt-then-MAC，先验 MAC 再解密）
- PBKDF2-HMAC-SHA256（随机盐 16 字节 + 200,000 次迭代）派生包装密钥
- 改密码零重加密（只重新包装主密钥）；容器格式 v2，兼容读取 v1 旧容器

### ✨ 功能
- 目录树 / 面包屑浏览，导入文件与文件夹，双击打开（编辑自动回写保险库）
- 重命名 / 复制 / 剪切 / 粘贴 / 删除 / 属性；「解密」= 导出明文副本
- 深浅主题、窗口大小与位置记忆、无边框自绘标题栏（拖动 / 边缘缩放）
- 空闲自动锁定（界面无操作达到设定时长）+ 定点临时解锁模式
- 阶梯锁定防爆破：连续 5 次错误 → 15 分钟 / 1 小时 / 2 小时…

### 🛡️ 安全
- 命令白名单 / 来源白名单 / 参数白名单（禁路径穿越、系统条目、越权调用）
- 密钥及时清零；明文临时文件用后即删；不联网、不写注册表

### 🔧 v1.0.0 包含的修复
- 修复左侧目录树点击无法切换文件夹、当前项不高亮
- 修复窗口顶部边缘拖动无法调整高度（边缘抓取区 12px + 顶部提示条）
- 修复点击任务栏图标不能收起窗口、Alt+F4 无效
- 修复日志页显示演示路径（现显示真实日志文件路径）
- 自动锁定改为真正的"界面无操作"空闲检测

### 🖥️ 环境要求
Windows 10 / 11 + Microsoft Edge WebView2 Runtime（系统通常自带）

### 🧪 质量
源码附 55 项核心逻辑自动化测试，全部通过。

> 首次运行请设置主密码；**忘记密码无法恢复数据**，请定期备份 `DH-BOX.vault`。
